# Programming Learning Platform Developer Handoff

Start with **product-specification.html** in a browser or **product-specification.md** in an editor. It covers all 30 requested areas and ends with the copyable Instructions to the Senior Full-Stack Engineer brief.

Open **curriculum-audit.html** to inspect all 182 days, the supporting material and the searchable source mapping. The HTML files are self contained and can be opened directly; they need no local server or internet for their document content.

| File | Purpose |
| --- | --- |
| product-specification.html | Navigable product and engineering specification |
| product-specification.md | Editable specification with the same content |
| curriculum-audit.html | Full curriculum and source to website audit |
| curriculum-source.json | Exact source archive, proposed content hierarchy and explicit product rules |
| source-to-website.csv | Exhaustive 2329 row mapping, including headers/footers |
| curriculum-days.csv | Complete daily instructions, tasks, AI policy and completion criteria for 182 days |
| schema.sql | Executable reference SQLite database schema for implementation in Drizzle |
| verification-report.json | Handoff inventory, fidelity and reference schema checks |

The source manual is preserved in its original Serbian Latin wording. English product decisions are separate. Counts are 6 phases, 26 weeks, 182 days, 548 task lines, 7 preparation tasks, 7 appendices, 14 scorecard dimensions, 19 hyperlink occurrences and 12 distinct original hyperlink targets. A task line may contain multiple coding problems or a constraint; 548 is not a count of individual programming problems.

The source mapping covers 2327 substantive body paragraphs plus two header/footer records. Raw extraction retains all 2365 body paragraphs, including 38 layout-only records. Table coordinates preserve relationships in the 197 original tables. The source fingerprint is recorded in the specification and JSON.

This package specifies the application; it is not an implemented learning application. The schema and source preservation checks are verified independently. App routes, account security, UI behavior, accessibility and the restart journey remain delivery acceptance tests for the engineer. The original external URLs have been preserved; their full current content and availability have not been exhaustively audited.

Keep the files together so links between documents continue to work. The archive programming-platform-handoff.zip contains the complete handoff, excluding itself. No intermediate build scripts or private credentials are included.
