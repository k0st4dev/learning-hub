## Fixed engineering decisions

- Use the requested Next.js App Router, React, TypeScript, SQLite, Drizzle/better-sqlite3, Tailwind and Zod stack. Argon2id and opaque database sessions follow the specified parameters and lifecycle.
- Use only local runtime storage and free dependencies/assets. Maintain dependency licence attribution and required notices, including transitive redistributed components. No required external account, credit card, trial, paid API or font CDN.
- Preserve Serbian Latin content with `lang="sr-Latn"`, an English UI dictionary, source provenance and separately identified product explanations. Do not invent lecture content, hints, solutions or external deep links.
- Keep auth, repositories, services, importer and pure progress/resume rules separate. Validate server inputs and ownership at every entry point. Use committed reviewed migrations, WAL/FULL durability and safe file-based test databases.
- Course progress derives from required lesson/exercise units: initially 364. Floor displayed percentages; reopening recalculates affected totals. Preparation/tasks/notes/resources/scorecards are not extra progress units.
- Confirm saves only after commit. Use explicit desired states, expected revisions and idempotency keys. Preserve drafts on failures without silently switching to browser persistence.
- Published releases remain immutable. Setup is nondestructive; enrollment upgrades are explicit, mapped and backed up.

## Blockers and verification limits found during review

1. The installed Node version manager blocks `npm` with NVM4306: delegated npm script identity changed since it was trusted. Do not bypass that trust check or blindly re-trust changed files. M0 must inspect/repair a trusted runtime installation or use an independently verified compatible toolchain, then verify native packages. No machine-wide runtime changes have been made.
2. The current execution host is Windows. Actual macOS/Linux installation evidence needs those OS environments. Real OS reboot and screen-reader review also need explicit manual evidence. These are final acceptance dependencies, not reasons to stop independent implementation.
3. Native module downloads/dependency installation have not yet been tested; required network permissions will be requested if the environment blocks them. There is no proposed paid dependency.

No missing handoff file or unresolved curriculum contradiction was found that prevents planning. External learning pages were preserved rather than freshly availability-verified; source assertions keep their original snapshot dates.

## Focused session protocol

Start each implementation task from PROJECT_STATUS.md: objective, specification section references, relevant files, constraints, and precise completion checks. Read other source sections only when needed. End each task with checks run, results, architectural decisions, unresolved issues and the exact next task. Report milestone functionality, verification, blockers and next step briefly. After plan agreement, routine implementation choices need no renewed approval. Flag material changes to curriculum, security, architecture, cost or scope before implementing them.
