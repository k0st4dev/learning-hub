## Behavior and decisions

All 182 study pages and day overviews now provide an explicit Mark study complete action. Only acknowledged database saves award the lesson's one required unit; exercise completion remains independent. The day fraction is 0/2, 1/2 or 2/2. Confirmed study completion offers Continue to exercise. Reopening requires a confirmation and removes only lesson credit, keeping all exercise work.

Study this day selects the first incomplete study/exercise unit of that day and records started study without credit. Open reference records Last opened without replacing the unfinished active study cursor. Hydrated lesson/exercise visits perform that same owned reference mutation; GET rendering itself never writes progress. Day-overview visits do not automatically select a unit. Later-day work displays an explicit out-of-sequence notice and links the earliest incomplete work. Completed days cannot be selected as unfinished study. Server guards also prevent completed-unit study selection and repeated completion confirmations from overwriting active unfinished work.

Study, exercise and cursor actions share revision checks, pending locks, account-switch protection, identical uncertain retries, accessible feedback and explicit conflict resolution. Unsaved exercise text is protected when Study this day would navigate to another unit. Browser Back/Forward draft protection remains pending. Primary completion and reopening actions still use the existing transactional API and durable SQLite receipts. No SQL migration, dependency, licence or published curriculum change.
