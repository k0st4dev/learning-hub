# M5 step 5 — protection for unsaved history navigation

Updated 2026-10-06. Implementation and automated checks are complete; **the browser verification gate is still pending**. Do not advance to the M5 integration gate or declare this step fully verified yet. The final MVP and A01–A26 also remain open.

## Implementation

Document-lifetime history tracking starts in the root layout, including clean pages visited before an exercise. Each entry preserves the existing Next router state and adds only a document UUID and numeric position. No dummy entry is pushed, no student draft is put into browser history/storage, and no server write is performed by this protection.

The capture-phase popstate listener runs before Next's ordinary router listener. It uses the existing cancelable `learning:before-leave` event, so the same exercise confirmation protects links, sign-out and Back/Forward. On cancellation, the editor stays mounted and a compensating traversal restores the actual previous history position. The restoration event is withheld from the router without asking twice. Accepted traversal continues through Next normally. Older Forward entries remain available; no replacement navigation truncates them. Multi-entry jumps use the indexed distance, and additional traversal during restoration is absorbed.

Same-origin/path/query section changes remain navigable without prompting, preserving unsaved exercise input and the existing allowlisted section behavior. Native fragment entries retain the same page's router tree and receive a position marker. Full document departure continues to use the existing native beforeunload warning. Entries belonging to other documents are not assigned an invented traversal distance. The existing guard remains active for dirty input, pending requests and uncertain receipts, retaining failed-save/account/conflict behavior. Modified/new-tab/download links remain exempt; Alt joins the existing modifier-key exclusions.

Root tracking installs once per document, including React's development Strict Mode effect replay. It remains active between routes. Applied SQL, progress mutations, receipts, authentication, dependencies and published source content are unchanged. No paid service or licence was added.

Implementation references: installed `next/dist/client/components/app-router.js` (the router's state-preserving History API wrappers and bubbling popstate listener); [MDN popstate](https://developer.mozilla.org/en-US/docs/Web/API/Window/popstate_event). The implementation restores history after cancellation rather than assuming popstate itself cancels a traversal. Navigation API documentation was reviewed, but that API is not a required dependency.
